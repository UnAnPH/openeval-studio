you are tasked with debugging a multi-phase delivery routing engine located in /app. the codebase is currently failing tests due to logic bugs in the phase 2 pathfinding algorithms and the phase 3 scheduler. your first goal is to locate and fix the logic bugs in phase 2. your second goal is to debug the scheduler in phase 3 to pass strict thresholds on the average delivery time penalty per event (where an event is a batch of orders, and the penalty is the cumulative time elapsed before all orders in the batch are dropped off) on large city graphs.

you are strictly evaluated by a hidden test suite, which directly executes the binaries `/app/phase2` and `/app/phase3`. it verifies phase 2 simple directed loopless k-shortest paths by checking the count and lengths of the generated paths (with a 1e-3 matching tolerance, where k is determined by the test input queries), and verifies phase 3 by evaluating the average delivery time penalty per event against a hard threshold. you must modify the source code under /app to ensure these exact executables build successfully and the test suite passes entirely.
